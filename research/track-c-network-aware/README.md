# Track C — Network-Aware Inference

## Provisional question
Can visual evidence and network/system telemetry jointly identify unreliable computer-vision inference in telesurgical settings?

## Concept
Investigate reliability functions of the form `R = f(X, N)`, where `X` represents visual evidence and `N` represents network/system state.
