# Track C — Network-Aware Inference

## Status after P0.7 (2026-11-12)
**PRIMARY** question (RQ1) of the integrated study. See `../../literature/intersection-analysis/track-decision.md`.

## Concept
Investigate reliability functions `R = f(X, N)`, where `X` is visual evidence (model outputs and decoded frames) and `N` is receiver-observable network/transport/decoder state. The decisive test is whether `N` adds detectable value **beyond a strong video-only monitor**.

## Residual risk
**High.** Generic networking/video-analytics venues were only shallowly searched in P0.7. Phase 1 task P1.1 is a blocking targeted search.
