# Dataset Registry

Do not commit restricted or large datasets to Git.

For every candidate dataset record:
- official name and citation;
- source/access URL;
- licence and redistribution terms;
- procedure/domain;
- modality;
- size;
- annotations;
- supported tasks;
- patient/site structure where disclosed;
- suitability for shift experiments;
- known limitations.

Dataset selection remains open during Phase 0.
