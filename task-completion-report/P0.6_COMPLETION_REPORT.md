## Core findings
1. **No universal safe latency was established.** Current guidelines and experiments use different latency definitions, systems, tasks and targets.
2. **Bandwidth requirement is robot/codec/traffic specific.** Constrained bandwidth can cause queueing/loss or trigger lower video bitrate/quality.
3. **Packet loss ≠ frame loss.** RTP packetization, reference dependencies, retransmission, FEC and decoder concealment mediate the visible effect.
4. **Jitter ≠ model-input jitter.** Buffers can absorb timing variation at the cost of added latency.
5. **Redundancy can hide path failure from the video stream.** Network telemetry can be bad while decoded video remains usable.
6. **Network access labels are insufficient.** 5G behavior depends on SA/NSA/QoS/congestion; satellite performance can vary sharply over time.
7. **Combined network impairments are already studied.** The 2026 multidimensional study directly examines latency × bandwidth × jitter × loss and their interactions.
8. **Direct downstream surgical-AI evidence remains limited but is not absent.** Endo-C6 includes packet-loss-burst corruption for temporal surgical/endoscopy VLMs.
9. The strongest unresolved programme intersection is a **mechanistic network/codec/decoder → standard surgical-CV reliability** study that tests the incremental value of network/system telemetry beyond received-video evidence.
